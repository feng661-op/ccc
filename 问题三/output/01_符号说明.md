# 问题3符号说明

> **与问题1、问题2统一基础口径。** 负载功率记为 $L$、负荷电量记为 $\ell$，光伏功率记为 $P^{pv}$、光伏电量记为 $p^{pv}$，外网交付电价统一记为 $c$，储能充/放电量记为 $x,y$，SOC记为 $S$。问题3只为“多时点信息更新—合同修订—多阶段场景树”新增符号。除特别说明外，优化变量均为10分钟电量口径（kWh）。

## 1. 集合、时间与下标

| 符号 | 含义 | 取值/单位 |
|---|---|---|
| $d$ | 自然日/决策日索引 | 2025-01-01 至 2025-12-31 |
| $j$ | 计划日144个合同槽索引 | $j=0,\ldots,143$ |
| $i$ | 自然日144个10分钟物理区间索引 | $i=0,\ldots,143$ |
| $t$ | 泛指某个10分钟交付时刻/区间 | 10 min |
| $\Delta t$ | 控制步长 | $1/6$ h |
| $\tau$ | 当日信息/合同事件时刻 | $\tau\in\{0,6,12,18\}$ h |
| $r$ | 合同阶段索引 | $r=0,1,2,3$ 对应0/6/12/18点 |
| $\omega$ | 场景树叶场景索引 | 主模型最多3个叶场景 |
| $g$ | 场景树信息节点索引 | 主模型最多9个节点 |
| $\nu$ | 光伏预测版本（forecast vintage） | 由发布时间唯一标识 |
| $\mathcal I_{d,\tau}$ | 事件 $(d,\tau)$ 可合法使用的信息集 | 仅已发生/已发布信息 |
| $\mathcal F_{d,\tau}$ | 事件前已冻结、不可修改的合同槽集合 | — |
| $\mathcal U_{d,\tau}$ | 事件后尚未交付、允许修改的合同槽集合 | — |

**计划日—自然日边界：** result3 的计划槽依次为 `0:10-0:20,...,23:50-24:00,0:00-0:10+1`。因此自然日 $d$ 的 $i=0$（00:00—00:10）执行计划日 $d-1$ 的 $j=143$；自然日 $i=1,\ldots,143$ 对应计划日 $d$ 的 $j=0,\ldots,142$。

## 5. 电价、费用与结算

| 符号 | 含义 | 单位 |
|---|---|---|
| $c_t$ | 交付时刻正常购电价 | 元/kWh |
| $5c_t$ | 紧急购电单价 | 元/kWh |
| $F^{plan}$ | 保留原合同电量费用 | 元 |
| $F^{cancel}$ | 下调取消结算费用 | 元 |
| $F^{add}$ | 上调追加费用 | 元 |
| $F^{regular}$ | 常规合同结算费用 | 元 |
| $F^{emg}$ | 紧急购电费用 | 元 |
| $F^{tot}$ | 总购电费用 | 元 |
| $\phi_{\omega,t}$ | LP中合同分段费用的epigraph变量 | 元 |
| $\mu_t$ | 系统额外1 kWh合同量的边际价值 | 元/kWh |

主结算固定为 `cancel_settlement + original_anchor + delivery_time`：
$$F_t^{plan}=c_t\min(A_t,B_t),\quad F_t^{cancel}=0.5c_t(B_t-A_t)^+,$$
$$F_t^{add}=1.5c_t(A_t-B_t)^+,\quad F_t^{emg}=5c_te_t,$$
$$F_t^{regular}=c_tA_t+0.5c_t|A_t-B_t|.$$

| 符号 | 含义 |
|---|---|
| $J_A,J_B,J_C,J_D$ | A/B/C/D 2×2因子组正式期总费用 |
