## 2. A/B/C/D 2×2因子对照

| 组别 | 更新PV vintage | 合同可调 | 总费用/元 |
|---|---|---|---:|
| A | 否 | 否 | 16,189,702.09 |
| B | 是 | 否 | 16,222,490.01 |
| C | 否 | 是 | 15,109,651.55 |
| D | 是 | 是 | **14,786,522.56** |

- $\Delta_{info}=J_B-J_A=32,787.92$元：冻结合同时，仅更新PV预测未单独降本；
- $\Delta_{flex}=J_C-J_A=-1,080,050.54$元：合同灵活性是主要直接收益；
- $\Delta_{int}=-355,916.90$元：信息更新与灵活修订存在有利交互；
- D较A共节省 **1,403,179.53元（8.667%）**。

因此论文应写“信息更新的价值依赖合同可调整空间”，不能写“新预测单独必然省钱”。

## 3. 多场景价值

# 问题3模型评价与论文表述建议

## 1. 推荐论文故事线

问题3的重点不是“多做三次预测”，而是把**物理SOC、0点原始合同、当前生效合同和合法信息版本**同时纳入状态。推荐主线：

> 严格事件信息边界 → forecast-vintage绝对目标对齐 → 因果负荷预测与成熟历史误差场景 → 信息节点共享的多阶段随机LP → 原始合同锚定的非对称调整结算 → 10分钟真实执行与SOC连续回放 → A/B/C/D和语义鲁棒性验证。

## 2. 主要亮点

1. **合同状态分层。** 将0点原始合同 $B$ 与当前生效合同 $A_	au$ 分离，修订后仍保留结算锚点。
2. **forecast vintage按绝对target对齐。** 避免把不同发布时间的相同lead列误当同一未来时刻。
3. **non-anticipativity写入变量拓扑。** 同一信息节点只建立一份合同变量，不允许场景提前知道未来分支。
4. **计划日/自然日双坐标。** 显式处理 `0:00-0:10+1`，费用和SOC可严格回算。
5. **因子实验分解信息价值。** A/B/C/D把“信息更新”和“合同灵活性”拆开，避免把联合收益错误归因给预测。
6. **经济死区解释。** 有限差分边际价值与0.5c/1.5c阈值的8个样本方向8/8一致。
7. **多层审计。** 未来信息反事实扰动、合同冻结、工作簿回读和五账本费用恒等式都实际验收。

## 3. 模型局限

1. 负荷预测仍为历史经验型，没有天气/温度等外生变量；
2. 场景最多3条，是小型代表树，不是完整条件概率分布；
3. 不考虑电池退化成本和售电机制；
4. continuation价值 $v_T=0.45$ 为建模参数而非题设常数；
5. revision-time语义存在非凸段，当前只做固定主策略全年重计并辅以代表日精确MILP，不能声称全年全局最优；
6. A/B/C/D是本年度数据上的实证效应，不外推为“任何年份更新预测单独都省钱”。

## 4. 推荐表述

- “主模型D正式期总费用为14.787百万元。”
- “D较冻结信息、冻结合同的A组节省1,403,179.53元。”
- “合同灵活性是直接收益主因，信息更新与灵活性存在有利交互。”
- “所有事件决策严格因果；16个未来扰动反事实样本对当前合同最大影响为0。”
- “SOC全程满足1200–10800 kWh并跨日连续。”

## 5. 禁止/不建议表述

- “更新预测本身一定降低成本。”——B比A高32,787.92元；
- “revision-time方案比主模型更优。”——14,720,004.19元是固定D策略重计，不是全年MILP最优；
- “场景树完全描述了真实概率分布。”——这里只是最多3条成熟历史analog代表场景；
- “允许售电或计划购电可退款。”——题面没有该机制；
- “2月1日SOC重新设为6000。”——实际连续继承1月；
- “日内修订可以改已经交付的合同。”——严格禁止。

## 6. 可直接用于论文的模型评价段

> 问题3模型的主要优势在于把合同承诺状态与信息到达过程同时纳入滚动优化。通过区分0点原始合同与日内生效合同、按绝对目标时刻对齐多版本光伏预测，并在场景树信息节点上共享合同变量，模型从结构上保证了non-anticipativity。全年回放显示，合同灵活性贡献了主要直接经济收益，而更新预测与合同灵活性之间存在明显协同；与此同时，未来扰动、合同冻结、SOC守恒、result3回读和多语义敏感性均通过独立审计，使结果具有较强可复核性。
