# 符号说明

## 集合与下标

| 符号 | 含义 |
|---|---|
| $t$ / $i$ | 10 分钟时段编号，$t = 1, 2, \dots, 144$（一天 144 段） |
| $\Delta t$ | 时段长度，$\Delta t = 1/6\ \text{h} = 10\ \text{min}$ |

## 已知量（输入数据，来自附件1、附录1）

| 符号 | 含义 | 单位 |
|---|---|---|
| $L_t$ | 第 $t$ 时段的小区负载功率 | kW |
| $\ell_t = L_t \cdot \Delta t$ | 第 $t$ 时段负载消耗能量 | kWh |
| $P_t$ | 第 $t$ 时段光伏发电预测功率 | kW |
| $p_t = P_t \cdot \Delta t$ | 第 $t$ 时段光伏预测发电量 | kWh |
| $c_t$ | 第 $t$ 时段外网电价 | 元/kWh |

## 决策变量

| 符号 | 含义 | 单位 |
|---|---|---|
| $b_t$ | 第 $t$ 时段计划购电量 | kWh |
| $x_t$ | 第 $t$ 时段储能充电量（输入电池的电能） | kWh |
| $y_t$ | 第 $t$ 时段储能放电量（电池输出的电能） | kWh |
| $S_t$ | 第 $t$ 时段起始时刻的储电量（SOC） | kWh |

## 参数（附录1 储能设备）

| 符号 | 取值 | 含义 |
|---|---|---|
| $C^{\max}$ | 12000 kWh | 储能最大容量 |
| $P^{\max}$ | 5000 kW | 最大充/放电功率 |
| $\bar X = P^{\max}\Delta t$ | 833.33 kWh | 每段最大充/放电能量 |
| $S^{\min}$ | 1200 kWh | SOC 安全下限 |
| $S^{\max}$ | 10800 kWh | SOC 安全上限 |
| $S_0$ | 6000 kWh | 0:00 与 24:00 的储电量（日周期） |
| $\eta_c$ | 0.9 | 充电效率 |
| $\eta_d$ | 1.0 | 放电效率（往返效率 90%） |

## 指标

| 符号 | 含义 |
|---|---|
| $F$ | 全天购电费（目标函数值），$F = \sum_t c_t b_t$ |
| $B^{\text{tot}} = \sum_t b_t$ | 全天购电量 |
| $F_0$ | 无储能基准费用（纯购电） |
