# 问题2符号说明

> **与问题1统一口径。** 问题2沿用问题1的基础符号：负载功率 $L$、负载电量 $\ell$、光伏功率 $P$、光伏电量 $p$、外网电价 $c$、计划购电量 $b$、储能充电量 $x$、放电量 $y$、储电量/SOC $S$。仅为全年滚动、场景不确定性和紧急购电新增日期下标、场景下标及辅助变量。

## 1. 集合与下标

| 符号 | 含义 | 取值/单位 |
|---|---|---|
| $d$ | 自然日索引 | $d=1,\ldots,365$ |
| $t$ | 每日计划购电10分钟时段索引 | $t=1,\ldots,144$ |
| $h$ | 单次MPC优化窗口内时段索引 | $h=0,\ldots,288$ |
| $\omega$ | 不确定性场景索引 | $\omega=1,\ldots,K$ |
| $K$ | 当日经验场景数 | 正式评价期 $K=9$ |
| $\Omega$ | 场景集合 | $\{1,\ldots,K\}$ |
| $\Delta t$ | 时段长度 | $1/6\ \mathrm{h}=10\ \mathrm{min}$ |
| $\mathcal F_d$ | 第 $d$ 日0:00可获得的信息集 | 历史已实现信息 |

> result2 的 $t=1$ 对应 `0:10-0:20`，$t=143$ 对应 `23:50-0:00+1`，$t=144$ 对应 `0:00-0:10+1`。因此自然日当天 `0:00-0:10` 仍执行前一日计划的第144段。

## 2. 负荷、光伏与净负荷（沿用问题1）

| 符号 | 含义 | 单位 |
|---|---|---|
| $L_{d,t}$ | 第 $d$ 日第 $t$ 时段实际负载功率 | kW |
| $\ell_{d,t}=L_{d,t}\Delta t$ | 10分钟实际负荷电量 | kWh |
| $P_{d,t}$ | 第 $d$ 日第 $t$ 时段实际光伏功率 | kW |
| $p_{d,t}=P_{d,t}\Delta t$ | 10分钟实际光伏发电量 | kWh |
| $n_{d,t}=\ell_{d,t}-p_{d,t}$ | 10分钟实际净负荷 | kWh |
| $\hat\ell_{d,t}$ | 0:00时对负荷电量的因果预测 | kWh |
| $\hat p_{d,t}$ | 0:00时对光伏电量的因果预测 | kWh |
| $\hat n_{d,t}=\hat\ell_{d,t}-\hat p_{d,t}$ | 点预测净负荷 | kWh |
| $r_{j,t}=n_{j,t}-\hat n_{j,t}$ | 历史第 $j$ 日净负荷预测残差 | kWh |
| $\tilde n_{\omega,h}$ | 场景 $\omega$ 下MPC窗口净负荷 | kWh |

## 3. 购电与储能变量（沿用问题1）

| 符号 | 含义 | 单位 |
|---|---|---|
| $b_{d,t}$ | 第 $d$ 日0:00制定的计划购电量 | kWh |
| $b_d^{lead}$ | 当天0:00-0:10执行的昨日末段已承诺购电量 | kWh |
| $b^{F}_{\omega,t}$ | 场景 $\omega$ 下下一日MPC续期购电量，仅作为滚动视野辅助变量 | kWh |
| $x_{\omega,h}$ | 场景下储能充电量 | kWh |
| $y_{\omega,h}$ | 场景下储能放电量 | kWh |
| $S_{\omega,h}$ | 场景下时段开始处储电量（SOC） | kWh |
| $e_{\omega,h}$ | 场景下紧急购电量 | kWh |
| $w_{d,h}$ | 实时执行时无法吸收的剩余电量/弃电量 | kWh |
| $S^{floor}_{d,h}$ | 实时执行采用的场景SOC风险储备底线 | kWh |

## 4. 电价、费用与风险损失

| 符号 | 含义 | 单位 |
|---|---|---|
| $c_t$ | 第 $t$ 个10分钟计划时段外网电价（与问题1一致） | 元/kWh |
| $5c_t$ | 紧急购电单价 | 元/kWh |
| $F^{plan}$ | 计划购电费用 | 元 |
| $F^{emg}$ | 紧急购电费用 | 元 |
| $F^{tot}=F^{plan}+F^{emg}$ | 总购电费用 | 元 |
| $Z_\omega$ | 场景 $\omega$ 在“lead段+当天计划”范围内的紧急购电损失 | 元 |

## 5. 储能参数（与问题1完全一致）

| 符号 | 含义 | 数值 |
|---|---|---:|
| $C^{max}$ | 储能额定最大容量 | 12000 kWh |
| $S^{min}$ | SOC安全下限 | 1200 kWh |
| $S^{max}$ | SOC安全上限 | 10800 kWh |
| $S_0$ | 2025-01-01 0:00初始储电量 | 6000 kWh |
| $P^{max}$ | 最大充/放电功率 | 5000 kW |
| $\bar X=P^{max}\Delta t$ | 单个10分钟最大充/放电量 | 833.333333 kWh |
| $\eta_c$ | 充电效率 | $\sqrt{0.9}=0.9486832981$ |
| $\eta_d$ | 放电效率 | $\sqrt{0.9}=0.9486832981$ |
| $\eta_c\eta_d$ | 往返效率 | 0.90 |

> 与问题1相同：题目仅给“充放电效率90%”，未分别给充、放单向效率，因此采用无偏对称拆分 $\eta_c=\eta_d=\sqrt{0.9}$。
