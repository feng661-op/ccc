最终 T01—T42 为 **42/42 PASS**。Price Oracle 仅作信息价值诊断；只有匹配条件下的 Full-information Oracle 才称严格现金下界。

## 5. 不要误读

- `0.960986` 是 1 月的结构相关证据，不是预测精度，更不是因果证明。
- 价格预测最终由公平 walk-forward 选为 `lag7/global`，不是结构 Ridge。
- R0 是历史轨迹按附件4重计价，只是压力参考，不是同口径因果基线。
- `eB=0`（紧急电不用于主动充电）是运行语义假设，不是物理定律；已有全期敏感性。
- E10 是固定主策略的结算 exposure，不是重新优化后的最优比较。
- 1 月用于选模/冻结，2—12 月只做冻结后的正式评价，不允许回调模型。
