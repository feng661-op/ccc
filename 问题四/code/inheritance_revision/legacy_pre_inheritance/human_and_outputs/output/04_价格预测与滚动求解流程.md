# 问题4价格预测与滚动求解流程

## 1. 先冻结，再正式评价

### 1月

1. 做附件4结构审计，得到价格—净负荷共振的机制证据；
2. 在统一因果walk-forward样本上比较价格预测候选；
3. 冻结`lag7/global`；
4. 比较B0/B1/B2，冻结Q4-2=B0、Q4-3=B1；
5. 冻结42天历史窗、物理/结算/风险口径。

### 2—12月

只按1月冻结配置逐日向前回放，不再选择参数。

## 2. Q4-2日流程

1. 00:00取得此时合法的历史负荷/PV和已揭示价格；
2. 不读取附件3未来PV；
3. 对未来波动价格作因果预测；
4. 生成当天合同/储能目标；
5. 每10分钟按当前已实现负荷/PV执行物理平衡；
6. 紧急缺口按当槽5倍实际电价结算；
7. 日终SOC连续进入下一天。

## 3. Q4-3事件流程

Q4-3在00:00、06:00、12:00、18:00收到对应PV预报版本：

- 已执行槽不可改；
- 原始00:00合同B保持结算锚；
- 未来未执行槽可形成新的绝对合同A；
- 每次事件的所有场景共享同一合同决策，保持非预见性；
- 10分钟执行层与Q4-2使用同一物理核。

## 4. 时间边界

自然日00:00—00:10仍执行上一计划行尾段；这也是2月1日必须承接1月31日计划尾列的原因。年度末同理另建 `../code/q4_2/tail_bridge.json` 与 `../code/q4_3/tail_bridge.json`，不伪造2026年附件4价格。

## 5. 一句话算法链

**已揭示信息 → 因果价格/PV信息 → 联合同源场景（若冻结启用）→ 事件层合同优化 → 10分钟同构物理执行 → 当槽结算 → 状态进入下一事件/下一日。**
