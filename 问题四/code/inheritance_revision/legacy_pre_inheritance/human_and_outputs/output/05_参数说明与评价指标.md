## 2. 主要经济指标

- 现金总费用：正式334天正常合同结算 + 紧急购电现金；
- 日费用CVaR95：正式期逐日现金费用上尾5%的平均；
- 最坏日费用：334天中最大单日现金；
- 紧急购电总量/天数：供电风险暴露；
- 未取合同电：已签合同但未物理取用的电量；
- 弃光：真实PV未利用量，和未取合同严格分开。

## 3. 物理/信息指标

- 最大物理平衡残差；
- SOC上下界与跨日连续性；
- 合同非预见性；
- Q4-2禁止附件3泄漏；
- Q4-3 PV vintage对齐；
- 价格模型训练目标必须严格早于决策时刻。

## 4. 预测指标

1月价格预测统一报告MAE、RMSE、q95绝对误差与CVaR95绝对误差。最终lag7：MAE=0.038663，RMSE=0.048887元/kWh。

预测指标只用于冻结预测器，不直接等价于经济收益。
