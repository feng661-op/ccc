# 问题4模型与结果说明

## 1. 模型定位

问题4在问题2/3的物理、合同和信息权限上新增“未来未知、实时揭示”的波动电价。核心不是把附件4全年实际价一次性塞进优化，而是模拟真实决策：已揭示价格可用、未来价格必须预测。

Q4-2严格继承问题2权限，不使用附件3未来PV；Q4-3严格继承问题3在00/06/12/18获得的新PV预报和后续合同调整权限。

## 2. 价格预测与冻结

1月结构审计得到价格异常与净负荷异常相关0.960986，但这只用于机制解释。所有价格模型在相同因果walk-forward样本上公平比较，最终最简单的`lag7/global`以MAE=0.038663元/kWh胜出。

复杂度也只在1月9—31日冻结：Q4-2最终B0，Q4-3最终B1，B2/DRO两分支均被门槛淘汰。正式2—12月不再调参。

## 3. 物理与结算

每10分钟显式区分合同电、光伏、紧急电、储能、未取合同和弃光；SOC按`eta_c=eta_d=sqrt(0.9)`连续递推。Q4-3后续合同A是绝对量，结算始终锚定00:00原始合同B。紧急购电按当槽实际价格5倍结算。

主模型`eB=0`，即紧急电只兜底负荷，不主动给电池充电；对此已做全期敏感性。

## 5. 基线解释

R0只是把历史既有轨迹按附件4重计价，不是公平基线。用于判断价格适应价值的是匹配C0：19,283,169.44元。正式Q4-2比C0约贵0.21%，配对block bootstrap区间也为正，因此本文明确不宣称Q4-2靠价格预测节费。

## 6. Oracle

Price Oracle仅已知未来价格：Q4-2 19,201,901.15元、Q4-3 16,154,889.86元，只作诊断。Full-information Oracle在匹配物理/结算/初末SOC等条件下放松未来信息，严格现金下界约为12.3024百万元。
