# 问题4符号说明

| 符号 | 含义 | 单位/备注 |
|---|---|---|
| d | 自然日索引 | 2025-02-01起正式评价 |
| t | 10分钟槽索引 | 每自然日144槽 |
| τ | 决策/事件时刻 | Q4-3主要为00/06/12/18 |
| c_{d,t} | 实际实时电价 | 元/kWh |
| ĉ_{d,t|τ} | τ时刻对未来电价的因果预测 | 元/kWh |
| L | 负荷电量 | kWh/10min |
| G | 光伏发电量 | kWh/10min |
| N | 净负荷 | 通常指L-G |
| B | 00:00形成的原始合同购电量 | kWh |
| A | 后续事件后的绝对合同购电量 | kWh；不是“增量” |
| q^L, q^B | 合同电直供负荷 / 给电池充电 | kWh |
| u | 未取用的合同电 | kWh |
| g^L, g^B | 光伏直供负荷 / 给电池充电 | kWh |
| κ | 真正弃光 | kWh |
| e^L, e^B | 紧急电供负荷 / 紧急电充电 | kWh；主模型e^B=0 |
| x, y | 电池充电量 / 放电量 | kWh |
| S_t | 槽开始时SOC | kWh |
| η_c, η_d | 充/放电效率 | 均为sqrt(0.9) |
| Φ(B,A;c) | 原始B锚定的合同结算函数 | 元 |
| α | CVaR置信水平 | B2候选参数 |
| λ | 风险权重 | B2候选参数 |
| ε | 经验分布Wasserstein漂移尺度 | 不是置信半径 |
| B0 | 因果点预测基线 | Q4-2最终冻结 |
| B1 | 联合残差场景SAA | Q4-3最终冻结 |
| B2 | 运输DRO+CVaR候选 | 两分支均未通过冻结门槛 |
| R0 | 前三问历史轨迹按附件4重计价 | 压力参考，不是匹配因果基线 |
| C0 | Q4-2同状态/同信息、但决策用固定分时价 | 匹配的无价格适应基线 |
| Price Oracle | 未来价格已知的诊断比较 | **不是**理论下界 |
| FI Oracle | 放松未来信息/非预见性的匹配全信息模型 | 匹配条件下严格现金下界 |

注意：计划表和自然日采用双时间坐标。自然日00:00—00:10对应上一计划行的`0:00-0:10+1`，不是当日新计划的第一列。
