# 问题4模型评价与论文表述建议

## 1. 可以作为亮点写的内容

- **严格信息边界**：附件4未来价格不偷看，Q4-2/Q4-3分别继承前两问权限；
- **双时间坐标**：正确处理`0:00-0:10+1`跨日桥接；
- **源—汇物理核统一**：合同电、PV、紧急电、储能分流可追踪；
- **复杂度由1月证据淘汰/保留**：Q4-2最终保留最简单B0，Q4-3保留B1，B2不因“算法高级”而强行进入主模型；
- **负结果如实报告**：Q4-2对匹配C0略贵0.21%；
- **Oracle边界严谨**：区分Price Oracle诊断和FI严格下界；
- **42项验收闭环**：信息、物理、结算、Excel、跨月/年尾和范围保护均独立检查。

## 2. 推荐表述

- “1月结构审计显示价格异常与净负荷异常高度共振，相关系数0.961；该结果作为机制证据。”
- “在统一因果walk-forward口径下，lag7取得最低MAE，因此冻结为正式价格预测器。”
- “Q4-3利用合法日内PV版本和合同调整权限显著降低正式现金与紧急购电。”
- “Q4-2的价格适应在正式期未取得现金节省，匹配C0比较反而约贵0.21%，因此不作节费宣称。”

## 3. 禁止/不建议表述

- 不要写“0.961证明价格可准确预测”或“价格由净负荷决定”。
- 不要写“Q4-2比固定价方案节费”，C0证据不支持。
- 不要把R0称作“公平基线”或“同口径基线”。
- 不要把Price Oracle称作“理论下界”。
- 不要把ε称作置信半径或覆盖保证。
- 不要把`eB=0`说成物理定律。
- 不要把E10固定策略重计价写成“替代结算下重新优化最优结果”。
- 不要说B2/DRO“效果最好”；正式冻结中两分支都未通过门槛。

## 4. 局限性

1. 当前槽负荷/PV使用当前测量近似，真实部署存在采样/通信延迟；已用lag-one敏感性量化影响。
2. 价格预测最终为简单lag7，说明复杂模型在当前数据/信息集下没有获得外样本优势。
3. Q4-2存在较高紧急购电暴露，不能用更复杂叙事掩盖。
4. 主模型紧急电不充电属于可解释运行规则，其敏感性在两分支方向并不一致。

## 5. 一句话结论

问题4最有说服力的地方不是“算法最复杂”，而是：**信息不偷看、物理可审计、复杂度事前冻结、负结果不粉饰、正式期连续回放可复核。**
